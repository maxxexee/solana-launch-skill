# Security

## Supported versions

This skill is a prototype for Solana protocol launches. No known vulnerabilities.

## Reporting vulnerabilities

Please report security issues privately via email to security@maxxexee.com. Do not open a public issue for a security problem.

## What this skill handles

- Pre-launch security gates (smart contract audits, multisig requirements)
- Token distribution validation
- Legal classification basics
- No on-chain vulnerability scanning is performed by this skill

## What this skill does NOT handle

- Real on-chain exploit detection
- Live DEX screening
- Fund safety guarantees

This is an AI-accessible playbook, not a security auditing tool. Do not rely on it for protecting real funds.
